# ModbusTool 用户手册

作者：工控菜鸡刘。本手册面向现场调试与仿真用户，说明 Master / Slave 两个程序的常用操作。协议细节与在线帮助见 `docs/help/`。

## 1. 程序组成

| 程序 | 用途 |
|---|---|
| ModbusMaster | 作为主站连接 PLC、仪表、变频器等从站设备，读取、写入与监视通信 |
| ModbusSlave | 作为从站仿真设备，提供四区寄存器、数据变化与故障注入 |

两个程序相互独立，可同时运行；在同一台机器上可用 `127.0.0.1` 完成主从环回。

## 2. 首次启动

1. 安装版从开始菜单启动；免安装版解压后双击 `ModbusMaster.exe` 或 `ModbusSlave.exe`。
2. 框架依赖包需要先安装对应 .NET Desktop Runtime；自包含包无需安装。
3. 默认主题为浅色，可在设置中切换深色、工业蓝、深灰工业或导入自定义主题。

## 3. ModbusMaster 主站

### 3.1 新建会话

1. 点击“新建会话”，选择 TCP 或串口 RTU。
2. TCP：填写主机地址与端口（默认 502）。
3. RTU：选择串口、波特率、数据位、校验位与停止位；波特率可从常用列表选择或输入正整数。
4. 保存后会话以独立 Tab 显示，每个会话拥有独立连接、轮询与趋势。

### 3.2 添加点位

1. 选择站号（Unit ID）与功能区域：线圈、离散输入、保持寄存器、输入寄存器。
2. 设置起始地址、数量、数据类型、字节序与显示格式。
3. 勾选“曲线”列可将该点位加入趋势图。
4. 支持从 CSV 导入点位表，也可将当前点位导出为 CSV。

### 3.3 启动轮询与写入

- 点击“启动轮询”，表格按周期刷新。
- 双击保持寄存器或线圈单元格写入新值；输入后先显示“写入中”，收到应答后回填真实值，超时或异常显示“写入失败”。
- 手动读写优先于周期轮询；写入期间轮询不会覆盖输入预览。

### 3.4 趋势图

- 打开“趋势”页查看实时曲线。
- 图例复选框控制曲线显隐；右键图例可修改颜色、线宽、线型或重置样式。
- 支持滚轮缩放、拖动平移、右键框选缩放、暂停更新、重置缩放。
- “快照 PNG”保存当前图表；“导出历史 CSV”导出采样数据。
- 曲线样式随工作区保存，重新打开后保持。

### 3.5 报文监视与日志

- 报文页按发送、接收、异常、CRC 错误分类染色，显示原始报文。
- 日志页支持级别、分类、会话、功能码、错误类型与关键字筛选。
- 支持选中或全部导出 CSV；Debug 级别默认关闭，可在日志面板开启。
- 日志文件按日期与大小滚动，默认单文件 5 MB、保留 5 个文件。

### 3.6 工作区

- 工作区保存会话、点位、趋势样式与通信设置，扩展名为 `.mbwork`。
- 支持新建、打开、另存为；旧版工作区会通过迁移器读取。
- 安装版可选择关联 `.mbwork` 文件，双击直接打开。

## 4. ModbusSlave 从站

### 4.1 启动监听

1. 设置站号，默认 `1`。
2. TCP：填写监听地址与端口，默认 `0.0.0.0:502`，点击“启动监听”。
3. RTU：选择串口与通信参数，点击“打开串口”。

### 4.2 编辑寄存器

- 在四区表格中直接编辑线圈、离散输入、保持寄存器、输入寄存器。
- 支持批量填充、清零与从文件加载。
- 数据持久化到寄存器文件；文件损坏时自动备份并重建。

### 4.3 数据仿真

- 固定值：保持当前值。
- 自增：按设定步长与周期递增。
- 随机：在最小值与最大值之间随机变化。
- 可对指定区域、地址范围、数据类型与字节序设置仿真。

### 4.4 故障注入

- 丢包：不返回响应。
- CRC 错误：篡改响应 CRC。
- 异常响应：返回指定 Modbus 异常码。
- 延时报文：延迟指定时间后响应。

故障注入用于验证主站超时、重试、异常处理与日志告警，请勿在正常生产链路上长期开启。

### 4.5 从站帮助与关于

- 帮助窗口按基础概述、功能说明、参数说明分组展示。
- 关于窗口显示版本、作者、开源协议、帮助文档链接与微信打赏码。

## 5. 主题与自定义

- 内置浅色、深色、工业蓝、深灰工业四套主题。
- 设置页可导出当前主题为 JSON，也可导入自定义主题。
- 主题文件包含窗口、面板、边框、文字、强调色与状态色；缺失键时使用默认值。

## 6. 本机环回

1. 从站 TCP 监听 `0.0.0.0:502`，站号 `1`。
2. 主站连接 `127.0.0.1:502`。
3. 主站添加站号 `1` 的保持寄存器块并启动轮询。
4. 在从站修改寄存器，观察主站表格、报文与趋势。
5. 主站双击写入，核对“写入中 → 真实值”的时序。

建议通信相关变更完成后连续运行 10 分钟，确认错误、超时、内存与句柄无异常增长。

## 7. 配置与数据文件

| 文件 | 说明 |
|---|---|
| `*.mbwork` | 主站工作区 |
| 从站配置文件 | 站号、通信参数、区域设置 |
| 寄存器数据文件 | 从站四区数据，支持旧版原始格式迁移 |
| 日志文件 | 按日期与大小滚动 |
| `version.json` | 版本信息 |
| `about.json` | 本地署名模板（界面不读取，可自行维护） |

配置与日志默认位于程序目录或用户指定的工作目录；请确保目录可写。现场使用前建议备份工作区。

## 8. 常见问题

- **启动提示缺少运行时**：安装对应 .NET Desktop Runtime，或改用自包含包。
- **端口 502 被占用**：改用其他端口，主站与从站保持一致；Windows 上 502 可能需要管理员权限。
- **串口打不开**：确认驱动、端口号、波特率与校验位，并关闭占用该串口的其他程序。
- **趋势无曲线**：确认点位已勾选“曲线”并已启动轮询；检查采样是否被暂停。
- **写入失败**：检查站号、地址、功能码、设备写权限与超时设置，查看报文与日志。
- **日志过大**：降低保留文件数量或关闭 Debug 级别。

## 9. 安全与现场注意

- 不要在现场保留包含设备地址、工艺参数或业务数据的原始报文。
- 故障注入与随机仿真仅用于测试环境。
- 修改通信参数前记录原值，避免影响生产设备。
- Windows 7 已停止安全更新，联网环境请优先使用 Windows 10/11。
