# 调试辅助文档

收集现场联调时最常见的问题与定位步骤，配合主站、从站的报文监视器与日志面板使用。

## 本地环回联调

1. 启动 ModbusSlave，通信方式选 TCP，监听 `127.0.0.1:502`，站号 1，保持寄存器数量按需设置。
2. 启动 ModbusMaster，新建会话，连接 `127.0.0.1:502`，站号 1，添加保持寄存器读取块。
3. 点击启动主站，报文监视器应出现发送（蓝）与正常接收（绿）配对报文，点位表格数值随从站数据变化。

无管理员权限时端口 502 可能被占用，可把两端改为 1502 等非保留端口。

## 常见异常

| 现象 | 可能原因 | 处理方式 |
|---|---|---|
| 全部请求超时 | 站号不匹配、端口未监听、串口被占用 | 核对站号与端口；确认从站显示“运行中”；关闭占用串口的其他程序 |
| 偶发 CRC 错误 | 波特率或校验参数不一致、线路干扰 | 两端统一波特率/数据位；缩短线缆并检查接地；适当加大报文间隔 |
| 异常响应（橙色） | 功能码不支持、寄存器地址越界 | 核对从站数据区大小与起始地址 |
| 写入后数值被刷新回旧值 | 应处于写入锁定窗口内 | 确认从站是否正常应答；超时会提示写入失败并解锁 |
| 队列持续增长 | 轮询周期过短、响应超时过长 | 增大轮询周期，或减小超时与重试次数 |
| 首次启动较慢 | 单文件版本需要自解压 | 属于正常现象，后续启动会明显加快 |

## 取证建议

- 报文监视器按站号与功能码筛选，先确认请求是否发出、从站是否回应。
- 日志面板按“错误”级别筛选，关注会话 ID、站号、功能码、报文摘要与耗时字段。
- 需要反馈问题时，导出日志 CSV 与报文截图，能显著缩短定位时间。
