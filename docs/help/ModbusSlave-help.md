# ModbusSlave 帮助

Modbus TCP / RTU 从站仿真器，用于在没有真实设备的情况下为主站提供数据源，也可注入故障验证主站的异常处理。顶部折叠分组配置监听参数，下方标签页管理寄存器、仿真与干扰。

> 本文本与程序内【帮助】窗口内容保持一致。

## 功能说明

| 模块 | 说明 |
|---|---|
| 从站仿真 | 顶部折叠分组配置站号、TCP/RTU 监听参数、数据持久化开关；下方标签页分区管理四区寄存器、字符串、仿真发生器、干扰报文、故障注入。 |
| 寄存器仿真 | 支持固定值、自增、随机值仿真，可设置仿真周期、数值上下限；支持寄存器批量修改、批量导入导出。 |
| 故障注入 | 支持模拟丢包、CRC 错误、异常响应、延时报文，用于验证主站异常处理逻辑。 |
| 报文监视器 | 支持按方向、站号、功能码、关键字筛选报文；CRC 错误标红、异常响应标橙。 |
| 日志查看 | 按日志级别、分类、关键字筛选，支持日志导出，记录通信耗时、异常详情。 |
| 数据安全 | 所有站号的数据区相互独立，程序退出时自动原子保存，避免寄存器数据损坏。 |

## 参数说明

监听参数修改后需要重新启动监听才会生效；仿真与故障注入参数可在线调整。

| 参数 | 默认值 | 说明 |
|---|---|---|
| 站号 | 1 | 从站地址，取值 1–247；主站请求的站号必须与之匹配，否则不应答。 |
| 监听端口 | 502 | Modbus TCP 标准端口；本机联调无管理员权限时可改用 1502 等非保留端口。 |
| 波特率 | 9600 | RTU 串口速率，下拉预置常用值，也可输入非标波特率。 |
| 数据位 | 8 | Modbus RTU 通常固定为 8 数据位、1 停止位。 |
| 寄存器显示条数 | 100 行 | 仅影响表格一次展示的行数，不会改变实际数据区大小。 |
| 仿真周期 | 按仿真项配置 | 仿真发生器的刷新间隔，决定自增与随机值的更新频率。 |
| 故障注入参数 | 关闭 | 丢包率、CRC 错误、异常响应码与延时时长，用于构造主站需要处理的异常场景。 |
