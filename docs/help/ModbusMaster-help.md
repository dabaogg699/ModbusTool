# ModbusMaster 帮助

面向工业现场的主站调试工具，支持 Modbus TCP 与 Modbus RTU 串口通信，可对 PLC、变频器、仪表、智能模块进行协议调试、仿真、压力测试与异常报文验证。阅读顺序建议先看功能说明了解界面分区，再按参数说明调整超时、重试与轮询策略。

> 本文本与程序内【帮助】窗口内容保持一致。

## 功能说明

| 模块 | 说明 |
|---|---|
| 主站调试 | 多 Tab 会话隔离，每个会话独立连接、独立轮询、独立趋势、独立报文监视，会话之间互不干扰。 |
| 点位配置 | 支持线圈、离散输入、保持寄存器、输入寄存器点位配置；支持 CSV 点位表导入导出，可自定义数据类型、字节序。 |
| 点位写入 | 双击点位单元格下发写入指令；写入等待应答期间点位锁定，不会被轮询数据覆盖；应答成功后同步刷新寄存器数值。 |
| 历史趋势 | 基于 ScottPlot 实时曲线渲染，支持图例曲线显隐、滚轮缩放、拖拽平移、十字准星读数；支持曲线图片、CSV 数据导出，恒定值点位自动补点。 |
| 报文监视器 | 支持按方向、站号、功能码筛选报文；CRC 错误标红、异常响应标橙。 |
| 日志查看 | 按日志级别、分类、关键字筛选，支持日志导出，携带会话 ID、站号、功能码、报文摘要、通信耗时。 |
| 通信设置 | TCP 默认 127.0.0.1:502 本地环回测试；RTU 串口预置常用波特率，支持自定义非标波特率。 |
| 资源释放 | 关闭 Tab 标签自动释放串口、Socket 等通信资源。 |

## 参数说明

下列默认值适用于多数现场设备；调整后随会话保存，重新打开程序仍然生效。

| 参数 | 默认值 | 说明 |
|---|---|---|
| 响应超时 | 1000 ms | 单次请求等待从站应答的最长时间，超过后按失败处理并计入超时统计。 |
| 重试次数 | 2 次 | 超时或通信错误后的重试上限，重试仍失败则该轮询点标记为错误。 |
| 重试间隔 | 50 ms | 两次重试之间的等待时间，现场干扰较大时可适当加大。 |
| 重连间隔 | 1000 ms | 连接中断后自动重连的等待时间。 |
| 报文间隔 | 10 ms | 相邻两帧之间的最小发送间隔，避免从站处理不过来导致丢帧。 |
| 队列容量 | 1000 条 | 待发送命令队列上限；队列满时优先丢弃轮询命令，手动命令优先发送。 |
| 轮询周期 | 按读取块配置 | 每个读取块独立配置的轮询间隔，与超时、重试共同决定单轮采集耗时。 |
| 写入锁 | 自动 | 从写入帧发出到收到应答期间锁定该点位显示，避免轮询数据覆盖用户输入；超时或异常时解锁并提示写入失败。 |
