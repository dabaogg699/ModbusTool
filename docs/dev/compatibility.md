# 系统兼容性

作者：工控菜鸡刘 · Copyright (c) 2026 工控菜鸡刘 · MIT License

作者：工控菜鸡刘。本文档说明 ModbusTool 在 Windows 7 SP1 至 Windows 11 上的兼容范围、依赖条件与验证方法。

## 1. 目标系统

| 系统 | net8 产物 | net6 产物 | 说明 |
|---|---|---|---|
| Windows 7 SP1 x64 | 不支持 | 支持 | 需 SP1 与 KB2533623；建议使用 net6 自包含包 |
| Windows 8.1 x64 | 不支持 | 支持 | 建议使用 net6 产物 |
| Windows 10 1809+ x64 | 支持 | 支持 | 两个分支均可运行 |
| Windows 11 x64 | 支持 | 支持 | 推荐 net8 产物 |

net8 版本的桌面运行时最低要求为 Windows 10 1809；Windows 7 无法安装 .NET 8 桌面运行时，因此不提供 net8 产物。

## 2. 运行时依赖

| 产物 | 运行时 |
|---|---|
| net8 框架依赖包 / net8 安装包 | .NET 8 Desktop Runtime（x64） |
| net8 自包含包 | 无 |
| net6 框架依赖包 / net6 安装包 | .NET 6 Desktop Runtime（x64） |
| net6 自包含包 | 无 |

安装包会在安装前检查 `C:\Program Files\dotnet\shared\Microsoft.WindowsDesktop.App` 下是否存在对应主版本；缺失时弹窗引导打开官方下载页并中止安装。

## 3. 第三方依赖差异

| 组件 | net8 | net6 | 说明 |
|---|---|---|---|
| ScottPlot.WPF | 5.1.59 | 5.0.55 | net6 使用仍提供 `net6.0-windows` 资产的版本 |
| SkiaSharp | 3.119.0 | 2.88.9 | 由 ScottPlot 传递依赖 |
| System.IO.Ports | 8.0.0 | 8.0.0 | 同时提供 net6 / net8 资产 |

趋势、主题、写入时序与多会话逻辑在两套目标下保持一致；差异仅在图表库内部实现。

## 4. Windows 7 注意事项

1. 必须安装 SP1 与 KB2533623（通用 C 运行时加载补丁）。
2. 建议使用 net6 **自包含**包，避免额外安装运行时的网络与权限问题。
3. Windows 7 的 TLS 1.2 默认未启用；更新检查等网络功能可能受限，串口与局域网 TCP 不受影响。
4. 串口功能依赖系统自带驱动与硬件厂商驱动；USB-485 转换器需使用支持 Windows 7 的驱动版本。
5. 高 DPI 缩放在 Windows 7 上表现有限，建议使用 100% 或 125% 缩放。
6. Windows 7 已停止安全更新，不建议在联网生产环境长期使用。

## 6. 已知限制

- 仅支持 Windows x64；ARM64、x86 未验证。
- 不覆盖真实 485 电气特性、干扰、终端电阻与设备私有协议。
- 自包含包首次启动需解压原生依赖，启动时间略长。
- 部分杀毒软件可能对自包含单文件给出启发式提示，可将程序目录加入信任列表。
- Windows 7 的串口驱动限制属于系统底层问题，程序无法完全规避。
